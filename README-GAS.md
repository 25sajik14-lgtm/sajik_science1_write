# 구글 앱스 스크립트(Google Apps Script, GAS) 배포 가이드

이 앱은 React와 Vite로 만들어졌으며, 구글 앱스 스크립트 환경에서 실행될 수 있도록 모든 자바스크립트와 CSS 코드를 하나의 HTML 파일로 묶어주는 `vite-plugin-singlefile`이 설정되어 있습니다.

아래 단계에 따라 앱을 구글 앱스 스크립트로 배포하세요.

## 1. 빌드하기
먼저 앱을 빌드하여 배포용 파일을 생성해야 합니다.
AI Studio 환경에서 좌측 파일 탐색기의 터미널이나 셸을 열고 아래 명령어를 실행하세요.
(또는 AI에게 "앱을 빌드해줘"라고 요청하셔도 됩니다.)

```bash
npm run build
```

빌드가 완료되면 `dist` 폴더 안에 `index.html` 파일이 생성됩니다. 이 파일 하나에 앱의 모든 코드가 포함되어 있습니다.

## 2. 구글 앱스 스크립트 프로젝트 생성
1. [구글 앱스 스크립트 대시보드](https://script.google.com/)에 접속합니다.
2. **새 프로젝트**를 클릭합니다.
3. 프로젝트 이름을 "나도 이제 입자!" 등으로 변경합니다.

## 3. 코드 복사 및 붙여넣기
1. 앱스 스크립트 편집기에 기본으로 생성된 `코드.gs` 파일의 내용을 지우고, 이 프로젝트의 `Code.gs` 파일 내용을 복사하여 붙여넣습니다.
   ```javascript
   function doGet(e) {
     return HtmlService.createHtmlOutputFromFile('index')
       .setTitle('나도 이제 입자!')
       .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL)
       .addMetaTag('viewport', 'width=device-width, initial-scale=1');
   }
   ```
2. 편집기 상단의 **+** 버튼을 누르고 **HTML**을 선택하여 새 파일을 만듭니다.
3. 파일 이름을 **`index`** 로 지정합니다. (자동으로 `index.html`이 됩니다.)
4. 이 프로젝트에서 빌드된 `dist/index.html` 파일의 **모든 내용**을 복사하여, 방금 만든 앱스 스크립트의 `index.html` 파일에 붙여넣습니다. (기존 내용은 모두 지웁니다.)

## 4. 웹 앱으로 배포하기
1. 앱스 스크립트 편집기 우측 상단의 **배포** 버튼을 클릭하고 **새 배포**를 선택합니다.
2. '유형 선택' 옆의 톱니바퀴 아이콘을 클릭하고 **웹 앱**을 선택합니다.
3. 설정:
   - **설명**: 첫 배포 (또는 원하는 설명)
   - **다음 사용자 권한으로 실행**: 나 (웹 앱에 접속하는 사용자가 아닌, 스크립트 소유자의 권한으로 Firebase 등에 접근하게 됩니다.)
   - **액세스할 수 있는 사용자**: 모든 사용자 (또는 구글 계정이 있는 모든 사용자)
4. **배포** 버튼을 클릭합니다.
5. (필요시) 권한 검토 창이 뜨면 계정을 선택하고 '고급' -> '안전하지 않음으로 이동'을 클릭하여 권한을 허용합니다.
6. 배포가 완료되면 제공되는 **웹 앱 URL**을 복사하여 학생들에게 공유하면 됩니다!

---
**참고사항:**
* 코드를 수정하고 다시 배포할 때는 항상 `npm run build`를 다시 실행하여 새로운 `dist/index.html` 코드를 복사해야 합니다.
* 다시 배포할 때는 '새 배포' 대신 '배포 관리'에서 기존 배포를 연필 아이콘으로 수정하여 **새 버전**으로 배포해야 URL이 바뀌지 않습니다.
